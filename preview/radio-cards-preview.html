Radio Cards · Live preview

Two solutions for the same radio-card pattern. Both use Atlas / Lens Figma tokens. Hover, click, and Tab through each group to see the full state matrix (default · hover · pressed · focused · selected).

Solution 1 — built on the Atlas Card

Default · hover (soft elevation) · pressed (variant-subtle fill) · focused (UI/Focus/Main ring) · selected (blue outline).

Solution 2 — built on the Atlas Button Tile

Default · hover (action-secondary fill) · pressed (action-secondary-active) · focused (focus-ring shadow) · selected (blue outline).

This preview uses the same CSS in tokens/radio-card.css + tokens/radio-button-tile.css. To run the real React app: cd react && npm install && npm run dev → http://127.0.0.1:5173. Angular: cd angular && npm install && npm start → http://127.0.0.1:4200.
