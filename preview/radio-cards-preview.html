Radio Cards · Live preview

Radio-card pattern built on the Atlas Card component. All values come from Atlas / Lens Figma tokens. Hover, click, and Tab through the group to see the full state matrix (default · hover · pressed · focused · selected · disabled).

Built on the Atlas Card

Default · hover (asymmetric Elevation/Low shadow) · pressed (variant-subtle fill) · focused (UI/Focus/Main ring) · selected (blue outline) · disabled (outline-disabled radio + type-disabled label).
